## 6. CHALLENGES AND SOLUTIONS

1. **Natural Language Ambiguity & Missing Parameters:**
   * *Problem:* When users entered incomplete prompts (e.g. *"Wedding in Colombo"* without guest count or budget), the LLM returned null or hallucinated arbitrary values.
   * *Solution:* Built a dual-layer extraction pipeline: regex heuristics extract numbers and known Sri Lankan districts, and the Pydantic schema enforces default boundary values (100 guests, LKR 500,000 min) with follow-up validation flags.
2. **Timezone Offset Shifting on Target Dates:**
   * *Problem:* Selecting a date in Flutter (UTC+5:30) shifted back by one day when serialized to UTC and displayed in React Web.
   * *Solution:* Standardized date transmission across Flutter, C# DTOs, and React to strict `yyyy-MM-dd` date strings, bypassing local timezone conversion during storage.
3. **Cross-Platform Microservice Identity Isolation:**
   * *Problem:* Calling Python FastAPI directly from clients risked JWT forgery and bypassed database validation.
   * *Solution:* Routed all AI requests through the ASP.NET Core `AiWorkflowService` gateway, validating JWT claims and attaching the caller's verified `CustomerId` before calling the AI service.

## 9. AI REFLECTION
I used Google Antigravity (Gemini 3.7 Flash) and GitHub Copilot for drafting regular expressions, scaffolding repetitive DTOs, and creating initial Flutter UI widget layouts. AI provided high productivity gains when translating schema definitions between Python Pydantic models, C# DTOs, and Dart models.

However, AI struggled with contextual natural language extraction for Sri Lankan geographic names and local currency formats (e.g., *"2.5M"*, *"LKR 1,500,000"*, *"Nuwara Eliya"*). The models frequently misinterpreted district names as event types and failed on colloquial date representations.

To resolve this, I implemented custom regex patterns and validation rules to sanitize raw prompt inputs before passing them to the model, and wrapped the output in strict Pydantic schemas. This reinforced that AI prompt engineering cannot succeed without deterministic programmatic guardrails and local domain customization.
